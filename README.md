## 🛠️ Troubleshooting

If the app does not seem to update your Telegram bio, check the following common areas.

Make sure Spotify is playing on the same computer or through the same Spotify account that you connected to the app. If Spotify is paused or closed, there may not be a current track to show.

Make sure your Telegram account is still signed in inside the app. If the app has been closed for a long time, it may need you to sign in again.

Check that your internet connection is working. Both Spotify and Telegram need to communicate online for the status to update.

If your Telegram bio is not changing, confirm that the update option is turned on in the app. Some users may start the app but leave the sync control switched off.

If the app window does not open, try opening it again from your Downloads folder or from the place where you saved it. If Windows shows a security prompt, review the prompt and choose the option that lets you continue opening the application you downloaded.
